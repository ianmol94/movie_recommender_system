# 🎬 Movie Recommender System

A content-based movie recommendation system built using Python and machine learning techniques.

## 📌 Features
- Recommends similar movies based on user selection
- Uses cosine similarity for recommendations
- Built with Streamlit 
- Simple and interactive UI

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## 📂 Project Structure

├── app.py
├── movie_recommender.ipynb
├── README.md

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/ianmol94/movie_recommender_system.git

2. Navigate into the project folder:
   cd movie_recommender_system

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   streamlit run app.py
   # or
   python app.py

## 📊 How It Works
- Data preprocessing
- Feature extraction
- Similarity matrix computation
- Recommendation based on highest similarity scores
